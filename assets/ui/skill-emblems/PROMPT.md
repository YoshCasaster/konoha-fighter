# Skill emblem sprite atlas

Generated with the built-in imagegen tool. Source: `atlas.png` (3 columns × 2 rows). Run `node tools/ui-pipeline/build-skill-emblems.mjs` to rebuild six 192×192 PNGs in `apps/web/public/assets/ui/skill-emblems/`.

Prompt: Six equal, separated square pixel-art ability emblems on a transparent 3×2 atlas, without text or frames. Top row: charging wild boar; golden-orange sonic projectile; five angels circling blue lightning. Bottom row: blue ethanol barrel spraying flame; fist with blue-orange shockwave; regal crown against an inferno. Cohesive retro arcade pixel art with hard stepped edges, dramatic dark outlines, and saturated effects.
